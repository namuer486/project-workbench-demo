# 本机工作台

当前正式入口为 http://127.0.0.1:8765/ 。本机免登录；导入项目 JSON、检查预览后点击“保存并生成项目”。项目数据保存在本机 SQLite 数据库，刷新浏览器不会丢失，不需要提交 GitHub 或重新构建。8767 是原静态演示，不能保存到服务器。

## 日常操作

1. 在浏览器进入本机地址，点击“导入项目 JSON”。JSON 由 GPT + ipd-report-json Skill 生成，平台本身没有接入 GPT，也不直接解析报告文件。
2. 检查六维评价、项目问题与提炼，点击“保存并生成项目”。同一个 project.id 表示完整更新同一个项目；不同 ID 新建项目。
3. “数据同步”可以导入新版或下载当前 JSON。“项目设置”可生成或撤销只读查看链接。
4. 多人先后保存时检查版本；旧预览被其他人的更新超越会拒绝保存，请重新导入。每次保存保留历史 JSON，当前没有网页回滚按钮。

JSON 在服务器端校验后暂存于内存，预览有效期为 30 分钟；确认后才持久保存。JSON 是完整快照，缺少的旧条目会退出当前版本。表格导入保持原有“缺失条目保留”的规则，两种项目不能混写。

## 常驻运行

双击仓库根目录的“启动工作台.cmd”启动。平台会建立独立 Python 环境。host.ps1 在后台保持服务运行，Python 进程退出后等待 5 秒重新启动；数据库和口令不会重建。

执行 `powershell -ExecutionPolicy Bypass -File platform/install-startup.ps1` 后，当前 Windows 用户登录会自动启动后台服务。它是登录自启，不是 Windows 启动前的系统服务；电脑重启后需登录此用户。系统休眠、关机或断网时服务不可用。

当前用户启动目录的 ProjectWorkbench.lnk 是自启动入口；删除此快捷方式可取消登录自启。要停止后台服务，先停止 platform/data/host.pid 中对应且命令为本仓库 host.ps1 的进程，再停止本仓库 server.py 进程，避免保活程序重新启动它。停止前核对进程路径。

## 数据与备份

- 数据库：platform/data/workbench.sqlite3（包含项目、问题和历史 JSON）。
- 运行日志：platform/data/server.log、server-error.log。
- 此次升级前备份：platform/data/backups/ 下的 SQLite 文件。
- 升级前使用 SQLite backup API 创建一致备份；不要在运行中只复制主数据库文件而漏掉 WAL。恢复备份前先停止服务，保留现有数据库以便撤回。

本机免登录由启动脚本设置 WORKBENCH_REQUIRE_LOGIN=0，只绑定 127.0.0.1，并校验客户端和 Host 为本机。服务仍保留可选登录模式；同一个免登录入口暂不能供另一台电脑或公网访问。

## 后续外网入口

需要选定域名、HTTPS 网关或公司批准的内网穿透入口，再接到本机服务。接入时使用 WORKBENCH_REQUIRE_LOGIN=1、HTTPS 下 WORKBENCH_SECURE_COOKIE=1，或实现公司统一登录；反向代理应保留请求 Host。不要直接把当前免登录模式作为公网入口。

原来生成的 127.0.0.1 分享链接仅供本机；接好公网入口后应从公网网址打开平台，再生成对应网址。公网入口尚未部署，当前未修改防火墙或路由器，也没有向第三方上传项目。
