# TRACE 自评 — project-workbench-builder v1.0.0

## T 任务（Task）
把项目分散资料（Excel 问题表、会议纪要、版本总结、用研报告）整合为自包含 HTML 项目工作台，
并严格复现已交付成品的七大板块、IPD 阶段定位与六大衡量标签体系；支持数据源周期性低成本重同步。

## R 角色（Role）
- 使用者：游戏策划 / PM / 项目负责人（通过 AI 助手执行，无需写代码）。
- 执行者：AI 助手，按 SKILL.md 六步 + 四份附件完成解析、生成、校验、部署。

## A 动作（Action）
1. 需求分析：确认数据源 / 板块 / 标签体系 / 分层 / 版本语义 / 方法论框架 6 件事。
2. 数据管线：zipfile+re 零依赖解析（xlsx sharedStrings、docx 表格、HTML 实体解码）→ 图片压缩内嵌 → 富化派生字段 → `kb_data.json` → 双向关联表。
3. 结构搭建：内联真品样式表 + `__KB_DATA__` 占位符 + 七板块骨架。
4. 功能实现：提炼/时间轴/提交/周总览/图谱/数据洞察/AI 接口，含 safeStorage、网格斥力图谱、hash 路由。
5. 内容填充：主题聚类、通用性分层、总结条目、标签落到具体问题、人名归一、文案正式化。
6. 验证部署：node --check → 模板 lint → jsdom 烟测（含口径一致性断言）→ Edge 截图 → cloudstudio 部署。

## C 约束（Constraint）
纯前端自包含、零 CDN；数据与模板分离；标签/分类口径单点定义、四处同源；
分析类数据与流水数据分仓；个人目录只读+新增；见 SKILL.md 边界 8 条。

## E 产出（Expected）
- 单文件自包含 HTML 工作台（双击可开，本项目 520KB）
- `kb_data.json`（可复用于其他展示端）
- 可分享静态站 URL（重复部署 URL 不变）
- 可复用的重同步流程

## 自评结论
- 4 个示例全部来自真实项目（240 条明细 / 11 主题 / 六维标签 / 4 张定位图 18 标签 / 四段式方法论），无占位符。
- 边界 8 条覆盖真实踩坑：后端缺失、数据纪律、外部修改风险、硬编码妥协、人工标坐标需截图复核、页面体积。
- 口径一致性写成了可执行断言（维度筛选行数 = itemCount；图谱轴心 6/1），不靠肉眼。
- 安全扫描零命中（纯 md + css，无可执行脚本）。
- 结构自检：frontmatter 九字段齐全、category 命中官方「知识管理」、正文六章、示例 4 条、边界 8 条。
